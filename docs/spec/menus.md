# Menus

The menus: on a Mac its menu bar, and elsewhere a button in the window's top left corner that opens them. Both have the same items, which do the same, save what only a Mac does. An item with a key does the same as the key, and the key shows beside it. On a Mac the menus are the ones a Mac app has, in the usual order, with the usual items and the app's own commands where a Mac app would put them, and macOS adds its own, so nothing about them is new to learn. An item that can't act is greyed out, such as New Chat with no workspace open.

- **The app menu has About Roundhouse, Check for Updates…, Settings…, Services, Hide Roundhouse, Hide Others, Show All and Quit Roundhouse,** in the order every Mac app has them. About Roundhouse and Check for Updates… are one group, and Settings… and Services another, so the menu has fewer lines across it. Settings… is ⌘,, Hide Roundhouse is ⌘H, Hide Others is ⌥⌘H and Quit Roundhouse is ⌘Q. What Check for Updates… does is in `updates.md`, and what Settings… opens is in `settings.md`. *Unconfirmed:* Settings….
- **Quit Roundhouse, and closing the window, which quits too, first wait up to two seconds for what's on its way to the hub, then ask if quitting would still lose something,** such as what the hub didn't take in time, like a prompt, a comment or what's in the new-workspace dialog still on its way. It asks in an alert, "Quit Roundhouse?", saying how many chats and comments have something, as the update card does, with `Keep working` first, so Return loses nothing, and `Quit`. Quitting from the Dock, or as the Mac logs out, doesn't ask, since GPUI can't hold back a quit macOS starts, and it waits only a fifth of a second. *Unconfirmed.*
- **About Roundhouse says which build this is,** in an alert, as the sidebar names it. *Unconfirmed.*
- **The File menu has New Workspace, New Chat, New Terminal, Add Project… and Close Chat,** which are ⌘N, ⌘T, ⇧⌘T, no key and ⌘W, as a File menu makes and closes documents. Close Chat says Close File Tab while the file tab shows, Close Subagent Tab while the subagent tab does, and Close Terminal while a terminal does, since ⌘W closes that rather than the chat behind it. *Unconfirmed:* New Terminal's place in the menu, Close File Tab, Close Subagent Tab and Close Terminal.
- **The Edit menu has Undo, Redo, Cut, Copy, Paste and Select All,** with their usual keys, above what macOS adds, such as Emoji & Symbols. Each works in whichever text box has focus. Copy also copies text selected in a chat, and in a terminal, Copy, Paste and Select All work on what it shows, as its ⌘C, ⌘V and ⌘A do. *Unconfirmed:* Copy, Paste and Select All in a terminal.
- **Under them, Find has Find…, Find Next and Find Previous,** which are ⌘F, ⌘G and ⇧⌘G, as a Mac app has them, for the chat showing. What they do is in `chats.md`.
- **The View menu has Show Diff, ⇧⌘D, then Previous Workspace and Next Workspace, ⌘[ and ⌘],** above Enter Full Screen, which macOS adds. Show Diff says Hide Diff while the sidebar of changes is open, as the header's button does. Moving between chats has no item, because the menu bar can't show ⌃⇥ as an item's key.
- **The Window menu has Minimize, which is ⌘M, and Zoom,** below what macOS adds for arranging and tiling the window, and above its list of windows.

## Off the Mac

On Windows and Linux, where GPUI shows no menu bar, the app draws the menus itself, from the same list as a Mac's.

- **One button in the strip along the window's top opens the menus, in the top left corner beside the button that hides the sidebar,** as one menu, drawn as the app's other menus are, with each menu a submenu of it. It stays where it is, as that button does, and while the sidebar is hidden what's in the strip starts after both, as `sidebar.md` says. It's one button rather than a bar of the menus' names, which would take about 230px of the strip: more than fits beside the sidebar's button at the sidebar's narrowest, 220px, and while the sidebar is hidden it would push the workspace's name a long way right.
- **It comes first in the corner, with the button that hides the sidebar 4px after it, and it shows three lines, says Menu under the pointer, and opens the menus under it as it's pressed,** as a menu bar opens a menu, or with Enter or Space once Tab has reached it. It's in the same place over Settings, which has no sidebar to hide. *Unconfirmed.*
- **F10 opens them,** as it opens a Windows or Linux app's menus.
- **Alt, pressed and let go alone, opens them too.** *Not built.*
- **Choosing an item, Escape, F10 again, the button again or a click anywhere else closes them,** and focus goes back to where it was, which is what their items act on, so Edit's items edit the text box that had focus. A click elsewhere gives it to what it lands on instead, if that takes focus. *Unconfirmed.*
- **They're arranged as Windows arranges menus: File, Edit, View and Help.** There's no app menu: Settings… and Exit go to File, and About Roundhouse and Check for Updates… go to Help. Hide Roundhouse, Hide Others, Show All and the Window menu aren't there, since only a Mac hides an app, and the window's buttons, or the system, minimize and maximize it. File's other items, Edit with Find, and View are as a Mac has them.
- **File ends with Settings… and then Exit, each after a line, and Help has Check for Updates…, a line, then About Roundhouse,** last, as Windows apps have it. View has no line at its end, since nothing is added below it. *Unconfirmed.*
- **Linux says Quit where Windows says Exit,** as GNOME's and KDE's apps do. *Unconfirmed.*
- **An item that can't act is greyed out, and choosing it does nothing,** as on a Mac.
- **Each item's key shows as Windows and Linux write it, such as Ctrl+N, and Find Next and Find Previous show Ctrl+G and Ctrl+Shift+G rather than F3 and Shift+F3,** since those are the keys a Mac has, with Ctrl. *Unconfirmed.*
- **Each of the app's own keys has Ctrl where a Mac has ⌘,** as Windows and Linux apps have them, since there ⌘ is the Windows or Super key, which the system keeps for itself. So ⌘N is Ctrl+N, and ⇧⌘D is Ctrl+Shift+D. ⌘H, ⌥⌘H and ⌘M have no key there, since only a Mac hides an app, and Windows and Linux minimize a window themselves. Find Next and Find Previous are also F3 and Shift+F3 there. The Edit menu's keys are the text box's own there, such as Ctrl+Y for Redo.
- **In a terminal, where Ctrl+W, Ctrl+T, Ctrl+N, Ctrl+F and Ctrl+G belong to the shell, Close, New Workspace and Quit take Shift too,** as a terminal app has them, so Ctrl+Shift+W closes the terminal, Ctrl+Shift+N makes a new workspace and Ctrl+Shift+Q quits, and Ctrl+Shift+T opens a new terminal there as everywhere. Ctrl+Q, Ctrl+[, which is Escape, Ctrl+], F3 and Shift+F3 are the shell's there too, so New Chat and the workspace before and after are reached from the menus. Find is for a chat, so it does nothing in a terminal. Ctrl+Shift+C, Ctrl+Shift+V and Ctrl+Shift+A copy, paste and select all there, so Archive has no key there. *Unconfirmed:* Ctrl+Q, Ctrl+[, Ctrl+], F3 and Shift+F3 going to the shell, Ctrl+Shift+Q, and Archive having no key there.
