# Menus

The menu bar. An item with a key does the same as the key, and macOS shows the key beside it. The menus are the ones a Mac app has, in the usual order, with the usual items and the app's own commands where a Mac app would put them, and macOS adds its own, so nothing about them is new to learn. An item that can't act is greyed out, such as New Chat with no workspace open.

- **The app menu has About Roundhouse, Check for Updates…, Settings…, Services, Hide Roundhouse, Hide Others, Show All and Quit Roundhouse,** in the order every Mac app has them. About Roundhouse and Check for Updates… are one group, and Settings… and Services another, so the menu has fewer lines across it. Settings… is ⌘,, Hide Roundhouse is ⌘H, Hide Others is ⌥⌘H and Quit Roundhouse is ⌘Q. What Check for Updates… does is in `updates.md`, and what Settings… opens is in `settings.md`. *Unconfirmed:* Settings….
- **Quit Roundhouse, and closing the window, which quits too, first wait up to two seconds for what's on its way to the hub, then ask if quitting would still lose something,** such as what's left in the new-workspace dialog, or what the hub didn't take in time, such as a prompt or a comment still on its way. It asks in an alert, "Quit Roundhouse?", saying how many chats and comments have something, as the update card does, with `Keep working` first, so Return loses nothing, and `Quit`. Quitting from the Dock, or as the Mac logs out, doesn't ask, since GPUI can't hold back a quit macOS starts, and it waits only a fifth of a second. *Unconfirmed.*
- **About Roundhouse says which build this is,** in an alert, as the sidebar names it. *Unconfirmed.*
- **The File menu has New Workspace, New Chat, Add Project… and Close Chat,** which are ⌘N, ⌘T, no key and ⌘W, as a File menu makes and closes documents. Close Chat says Close File Tab while the file tab shows, and Close Subagent Tab while the subagent tab does, since ⌘W closes that rather than the chat behind it. *Unconfirmed:* Close File Tab and Close Subagent Tab.
- **The Edit menu has Undo, Redo, Cut, Copy, Paste and Select All,** with their usual keys, above what macOS adds, such as Emoji & Symbols. Each works in whichever text box has focus. Copy also copies text selected in a chat.
- **Under them, Find has Find…, Find Next and Find Previous,** which are ⌘F, ⌘G and ⇧⌘G, as a Mac app has them, for the chat showing. What they do is in `chats.md`.
- **The View menu has Show Diff, ⇧⌘D, then Previous Workspace and Next Workspace, ⌘[ and ⌘],** above Enter Full Screen, which macOS adds. Show Diff says Hide Diff while the sidebar of changes is open, as the header's button does. Moving between chats has no item, because the menu bar can't show ⌃⇥ as an item's key.
- **The Window menu has Minimize, which is ⌘M, and Zoom,** below what macOS adds for arranging and tiling the window, and above its list of windows.
